# Contao Simple Jobs

Ein Bundle um in Contao relativ _simpel_ Stellenanzeigen zu verwalten. Hauptaugenmerk ist auf Einfachheit gelegt:

- Listenanzeige
- Detailanzeige inkl. der Möglichkeit strukturierte Daten zu generieren

## Inserttags

```php
{{job::title}}

{{job::alias}}

{{job::datePosted}}

{{job::description}}

{{job::keywords}}
```
